# 🎨 CSS Mastery Repository

This repository contains all the **important CSS concepts** required for modern frontend development.  
It is designed as a **complete revision + practice resource** for beginners to intermediate developers.

---

## 🚀 About This Repository

This repo covers **core to advanced CSS topics** with examples and practice code.  
The goal is to build a **strong foundation in styling and layout techniques** used in real-world projects.

---

- Selectors (class, id, element)
- Colors & Backgrounds
- Units (px, %, em, rem, vw, vh)

- Margin
- Border
- Padding
- Content Box vs Border Box

### 🧱 Layout
- Display (block, inline, inline-block)

- Float & Clear

### 📦 Flexbox
- Flex Container & Items
- justify-content

- flex-direction

- gap

### 📐 Grid
- Grid Container
- Grid Template Rows & Columns
- Grid Areas
- Gap & Alignment

### 🎨 Styling
- Fonts & Typography
- Text Styling
- Shadows
- Gradients

### ✨ Advanced CSS
- Transitions
- Transform (scale, rotate, translate)
- Animations (@keyframes)
- CSS Variables (Custom Properties)

### 📱 Responsive Design
- Media Queries
- Mobile-first approach
- Breakpoints
